# 4.2.5 指定 KOL、有界分页与安全恢复

延续 4.2.4 的独立无奖励 KOL 观察、原身份、待回传队列、人工评价与签名更新。支持小红书、Bilibili 当前可访问的公开 DOM；不读取 Cookie、私有页面状态或绕过登录与验证码。

## 正常使用

在插件控制台进入 KOL 观察，添加创作者主页或指定内容 URL，也可导入名单 CSV。默认每任务最多 2 次详情尝试，失败也计预算；评论默认关闭。需要评论时明确设置数量（最多 20 条）和是否包含当前可见二级回复。每条内容最多 5 次评论页观察；页面不再变化、出现明确末页、达到数量或预算即停止。

主页历史任务支持有界连续发现：普通任务最多 3 次列表推进，历史任务最多 30 次；每次翻页或滚动都经服务端准入，恢复回滚列表也计预算。加载列表中的第 41 条以后不会被固定的前 40 条遮蔽。检查点仅保存候选 ID、已 ACK 的 ID 和推进次数，不是平台提供的完整游标；结果始终标注可见样本及未证明的源站覆盖。

周期任务使用服务端固定的 `scan_from` / `scan_until` 和 48 小时重叠。授权窗口至少为 `ceil(2 + interval_minutes / 1440)` 天，例如每 12 小时运行至少 3 天。中断后所需窗口超过用户授权时会明确阻断，不能自动扩大范围。日期仅有日精度时保守保留边界日；日期不可见保持未知。正常观察后 0 条新增也能结束本轮并进入下一周期，不冒充全量覆盖。`last_attempted_scan` 记录真实源动作准入，`last_complete_coverage` 不会凭客户端完成状态写成已覆盖。

## 账号核验与换设备

1. 在账号区域选择平台，点击打开账号页，由本人正常登录或切换账号。
2. 点击核对账号。仅从明确“我/我的主页”导航或 B 站头像导航获取当前主体；文章作者不会被当作登录用户。无法明确核验时停止绑定。
3. 原设备停止采集，待合法证据取得回执后，点击“停止并安全释放给另一设备”。未知源动作、未回传证据或检查点未确认会阻止释放；不会删除队列来强行通过。
4. 新设备登录同一中台身份并核验同一平台主体，展开“最近任务与覆盖范围”，点击“从检查点恢复到本设备”。已释放任务才可恢复，账号代数、准入次数和 ACK 均保留；不会重新获得完整预算。

新协议任务即使租约过期也保留原任务和候选，允许原设备安全释放。旧任务没有执行器绑定时不冒充安全迁移；未绑定主体的公开观察任务仍明确显示未核验，不能据此跨设备恢复。工作页与本人账号核验页分开，静默采集不抢前台。

## 停止、回传与错误

已采到的基础正文遇到评论验证码、停止或其他异常时仍保留，并继续合法回传。每条待回传记录最多自动发送 3 次；发送前持久计数和 60/120/240 秒退避，浏览器重启不清零。稳定请求 UUID 用于丢回执后的幂等核对。达到上限或旧队列发送历史未知时保留证据并暂停；本人可点击“重试待回传（最多 3 次）”开启新一轮回传，不自动恢复源站采集。

删除、私密、404 只在可见错误面板明确说明时分类；空白或加载中不猜测。相同平台的 `invalid_content` / `invalid_count` 在两条不同内容上复现时停止该平台解析；同内容重试不重复累计，作者不匹配与导航错页也不计入解析熔断。修复解析器后使用控制台恢复按钮，再明确继续采集；恢复不重置服务端预算。

纯图片评论保留实际平台 ID（若可见）、图片类型与媒体数量，原始文本保持空；界面显示“可见图片评论，无文字”占位。真实 DOM 父子关系才关联回复。不明身份的图片评论按样本保留，可能跨页重复，不会凭空文本误合并。回复总数仅取实际可见标签，未采回复数无法推知时显示未知。

手动停止会将当前已观察评论作为部分样本回传；当前版本没有可移植的源站评论游标。继续更多评论需要明确创建新内容观察任务并重新取得预算。B 站封闭 Shadow DOM 或未公开加载内容不可读时保持不可见，不承诺全评论树。

## 授权媒体与导出

内容详情的“导出授权媒体任务”读取最新观察记录中的媒体引用。输入不超过 200 字符的授权依据并确认后，导出最多 2 个图片、音频或视频资产的 JSON。仅接受公开 HTTPS 的 `xhscdn.com`、`xhsimg.com`、`hdslb.com` 及其子域；带查询参数、签名、片段或身份信息的 URL 不导出，也不会删掉签名再伪造可下载链接。引用发现不等于下载成功，浏览器没有新增下载权限。

授权下载和可选 OCR / ASR 使用仓库的后处理工具，默认只下载：

```sh
python3 crowd-kol/server/crowd/v4/postprocess/pipeline.py --manifest media-task.json --output-dir new-output-dir
# 明确需要时再加 --ocr 或 --asr --asr-model MODEL_PATH
```

后处理证据可从控制台导入，保留其独立来源，不替换 DOM 原文。JSON 导出附当前导出样本的字段缺失、平台分布和评论采样质量摘要；不能把样本指标推断成平台总体偏差。CSV 保持明细格式。
