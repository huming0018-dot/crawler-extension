🖥 你的系统：macOS 推荐 · 双击即装 · 自动升级

1
点击下方下载 安装.command（这是安装器，不是插件本体）
2
在「访达」里找到下载的文件，双击它（若提示「无法打开」：右键 → 打开 → 仍要打开，仅首次）
3
按提示输入一次开机密码（用于登记 Chrome 策略），脚本会自动重启 Chrome
4
完成！Chrome 会自己下载并安装插件（约 1 分钟），并自动打开「参与协议」页
⬇️ 下载 macOS 安装器 备用：插件 zip（手动模式）

✨ 以后插件升级全自动：每次发布新版本，Chrome 会在后台自动更新，不需要再运行任何脚本、不需要重装。

🖥 你的系统：Windows 推荐 · 双击即装 · 自动升级

1
点击下方下载 安装.bat（这是安装器，不是插件本体）
2
在「下载」文件夹找到它，双击运行（若出现蓝色 SmartScreen 提示 → 「更多信息」→「仍要运行」，仅首次）
3
弹出权限请求（UAC）点「是」——用于登记 Chrome 策略，脚本会自动重启 Chrome
4
完成！Chrome 会自己下载并安装插件（约 1 分钟），并自动打开「参与协议」页
⬇️ 下载 Windows 安装器 备用：插件 zip（手动模式）

✨ 以后插件升级全自动：每次发布新版本，Chrome 会在后台自动更新，不需要再运行任何脚本、不需要重装。

🖥 你的系统：Linux / 其他 手动安装

1
下载插件 zip 并解压到任意文件夹（如 ~/food-crowd）
2
打开 Chrome 或 Edge，地址栏输入 chrome://extensions（Edge 为 edge://extensions）
3
右上角开启「开发者模式」
4
点「加载已解压的扩展程序」→ 选择刚才解压出的文件夹
⬇️ 下载插件 zip

📱 检测到 Android 设备 手机版可用

1
安装 Kiwi Browser（Google Play 免费，Chromium 内核，支持 Chrome 扩展）
2
下载插件 zip，用 Kiwi 打开或先解压
3
Kiwi 地址栏输入 chrome://extensions → 开「开发者模式」→ 「+ 从 .zip/.crx 加载」→ 选 zip
4
填写参与编号 → 打开小红书页面 → 自动采集
⬇️ 下载插件 zip 📄 手机版详细教程

iPhone 暂不支持（苹果系统限制第三方扩展加载）。手机与电脑同一任务池，可换设备续采。

📱 想在手机上采集？

1
Android 手机：安装 Kiwi Browser，加载同一插件 zip —— 与电脑完全同步
2
iPhone：暂不支持（苹果系统限制），建议用电脑或 Android 手机
📲 查看手机版安装教程

✅ 安装完成后（两步开始采集）

1
首次安装会自动打开「参与协议」页（没打开就点右上角拼图图标 🧩 → 「众包美食家」→「选项」）：点 「我要加入」自动获得参与编号
2
阅读并同意《参与协议》→ 回到小红书页面（需已登录你的账号）→ 点插件图标 → 「▶ 启动采集」
✅ 之后全部自动：自动领任务 → 自动搜索 → 自动回传 → 自动领下一个任务。插件本身也会自动升级到最新版，无需任何手动操作。
