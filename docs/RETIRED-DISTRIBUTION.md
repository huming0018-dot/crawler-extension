## 源码证据与局限
- Windows 更新器用首个 `version="([0-9.]+)"` 匹配 XML；标准清单先包含 XML 声明，离线等价正则复现取到 1.0 而非扩展版本。文件镜像覆盖非原子，且未核查 robocopy 退出码即报告 applied。未运行 PowerShell/安装器。
- Windows 安装器在下载/校验新包前删除旧目录，下载仅检查文件存在；同时强制结束 Chrome、改默认配置和注册任务。不能将这种项目专用步骤当作完整通用安装能力。
- 发布器首次运行在创建 dist-release 前复制备份到该目录；隔离临时目录复现 cp 失败。后置 EXIT trap 覆盖 manifest 恢复 trap；缺少 CRX 仍生成对应更新清单。未运行完整发布器或读取发布凭据。
- 全树文本引用检查仅发现 README、install.html 和被删脚本引用这些文件；扩展运行时不导入它们。
