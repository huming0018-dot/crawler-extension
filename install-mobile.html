📱 众包美食家 · 手机版（Android）

两种参与方式：全自动采集（装一次插件，之后自己跑）或免安装网页提交（手动但零门槛）。

🦊 Firefox 安卓版（推荐 · 一键安装）

1
应用商店装 Firefox，用 Firefox 打开本页（或把 Firefox 设为默认浏览器后扫码进来）
2
点下方按钮 → 弹出「添加扩展」→ 点添加，装完自动打开协议页 → 「我要加入」→ 小红书登录一次 → 全自动
⬇️ 第一步：下载插件包（v3.4.9）

点上面按钮后文件会进 Firefox 的「下载」列表（不会直接安装，这是 Firefox 的规矩）。然后：

2
Firefox 右下角 ⋮ → 设置 → 最底部 关于 Firefox → 连点 Firefox 图标 5 下（开启开发者菜单）
3
返回设置 → 点新出现的 「从文件安装扩展」 → 选刚下载的 .xpi 文件 → 确认安装
4
弹出参与协议页 → 点「我要加入」→ 同意 → 开始。装好自动升级，以后刷小红书即自动采集

🤖 狐猴浏览器（全自动采集 · 装好就不用管）

1
应用商店搜索安装 狐猴浏览器（Lemur Browser）——仍在维护、支持 Chrome 扩展的安卓浏览器
2
点下方按钮下载插件 zip（不用解压）
3
狐猴浏览器：右下角菜单 → 扩展商店/扩展管理 → 选择「从本地安装/加载 zip」→ 选中刚下载的 crowd-extension-v3.4.8.zip
4
首次安装会自动打开「参与协议」页：点 「我要加入」自动获得编号 → 同意并开始
5
打开 www.xiaohongshu.com 登录你的账号，浏览器菜单里开启「桌面版网站」开关（让小红书按电脑版显示，插件才能正确识别页面）
✅ 之后全自动：插件自己领任务 → 搜索 → 采集 → 回传 → 领下一个任务。插件有新版本也会自动更新。
⬇️ 下载插件 v3.4.8（zip）
说明：旧方案用的 Kiwi 浏览器已于 2025 年初停止维护，不再推荐。若你已装 Kiwi 且一切正常，也可继续用它加载同一个 zip（步骤相同）。

⚡ 免安装 · 网页提交（任何手机都能用）

1
打开「手机提交」网页 → 点「我要加入」自动获得编号
2
中枢自动分配门店 → 去小红书搜该店 → 复制笔记网址（或 App 分享链接）→ 粘贴提交
🚀 打开手机提交页

iPhone 请用此方式（苹果系统不允许任何浏览器插件，这是平台硬限制）：用 Safari 打开后点底部「分享」按钮 →「添加到主屏幕」，之后从桌面图标直达提交页。
